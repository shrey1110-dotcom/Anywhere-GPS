# How this repository was published

This project existed as a local working tree before its first Git commit. The
publication history is a current-dated import of that work, organized into
modules, individual test cases, documentation, and patches for review.

The commits do not reconstruct the original day-by-day development timeline.
No commits are backdated or empty. Intermediate import commits can reference
files introduced later; use the completed main branch to build and test.

Dates in the hardware report refer to actual observations. A mock test result,
a successful command, a Maps observation, and locked persistence are separate
forms of evidence. Earlier failed experiments remain documented.
